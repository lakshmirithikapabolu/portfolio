# 🌟 Rithika Pabolu — Developer Portfolio

A responsive, high-performance developer portfolio built with **HTML5, CSS3, and JavaScript**, powered by **Vite**.

Designed with a sleek **black & neon glassmorphic aesthetic**, compact modern typography (**Open Sans**), and smooth micro-interactions.

---

## ✨ Features

- ⚡ **Neon & Black Glassmorphic UI**: Ultra-clean surfaces with neon cyan & green glowing accents.
- 📱 **Fully Responsive**: Mobile-first responsive layout across mobile, tablet, and desktop screens.
- 🎯 **Interactive Role Typer**: Dynamic animated typewriter effect for titles and honors.
- 🛸 **Animated Visuals**: Orbital planet mechanics and rotating gears for project previews.
- 🔍 **Interactive Project Modals**: Deep-dive modals displaying project architecture and GitHub repositories.
- 📬 **Direct Contact Integration**: One-click direct email, LinkedIn, and GitHub links.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Modern CSS3 (Variables, Flexbox, CSS Grid, Glassmorphism, Neon Glows)
- **Scripting**: Vanilla ES6+ JavaScript
- **Tooling & Bundling**: [Vite](https://vitejs.dev/)

---

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/lakshmirithikapabolu/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
npm run build
```
The optimized production output will be generated in the `dist/` directory, ready to deploy to **GitHub Pages**, **Vercel**, or **Netlify**.
